# Oshurkova Anastasia — UX/UI Portfolio

Одностраничное портфолио: кейс FitAI (мобильный UX от аудита до юзабилити-теста), блок «О себе», контакты.

- Свёрстано вручную (HTML/CSS, без сборщиков и зависимостей) — дизайн-система FitAI: Aldrich/Inter, primary #1A3EF5, сетка 8px, тап-зоны ≥44px, WCAG AA
- `index.html` — сайт
- `resume.html` — резюме (формат A4, печать в PDF)
- `img/` — экспорт макетов из Figma (13 файлов, суммарно ~7 МБ)

Deploy: GitHub Pages → Settings → Pages → Source: `Deploy from a branch` → `main` / `root`.
